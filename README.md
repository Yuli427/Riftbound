# Riftbound

Riftbound is a 2D game I made using Python and Pygame.

I built this project to practice game development and improve my understanding of object-oriented programming. The game uses Tiled for map design, and I separated different parts of the game into classes to keep the code organized.

## Features

- Player movement
- Collision detection
- Tile-based maps
- Transitions between different levels and maps
- Sprite animations
- Different game states and menu states
- Health, combat, and alliance systems
- Interactive game elements
- Sound effects and background music
- Player-centered camera scrolling
- Pause and restart system
- Win and lose states
  
## Technologies Used

- Python
- Pygame
- Tiled

## What I Learned

While working on this project, I learned more about:

- Object-oriented programming
- Using classes to organize a larger project
- Game loops and event handling
- Collision detection
- Loading and displaying tile maps
- Managing different game states
- Smooth camera scrolling that follow the player
